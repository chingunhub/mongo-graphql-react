Энэ курс зориуд том, бүгдийг нь дуусгах шаардлагагүй. Тиймээс эхлэхээсээ өмнө өөрт хэр их хэрэгтэйгээ яаж шийдэхийг эндээс харъя.

## Гурван шат

Курс гурван шаттай, шат бүрийн явцыг нүүр хуудаснаас харна.

| Шат | Module | Юунд зориулсан |
| --- | --- | --- |
| **1. Backend** | 0–9 | Гол зорилго. MongoDB, Mongoose болон бүрэн GraphQL API |
| **2. Full stack** | 10–13 | Нэмэлт сорилт. Жинхэнэ React бичиж, app-аа дуусгана |
| **3. Real systems** | 14–24 | Хэрэгтэй module-ээ хэрэгтэй үедээ ав |

1-р шатыг дуусгасан бол курс дууссан гэсэн үг. Чи жинхэнэ backend-ийг давхарга давхаргаар барьсан байна, тиймээс зогсоход ч, цааш явахаасаа өмнө түр амрахад ч сайн цэг. 3-р шатыг нээхэд 2-р шат шаардлагагүй, гэхдээ түүний сүүлийн module-ууд React ашигладаг.

## Хэр удаан үргэлжлэх вэ

Чамд хэр их цаг байгаагаас хамаарна, яарсных нь шагнал гэж байхгүй. Энд session гэдэг нь нэг удаа суугаад хийх хугацаа.

| 7 хоногт хэдэн session | Session бүрт хэдэн зүйл | 1-р шат | 2-р шат хүртэл |
| --- | --- | --- | --- |
| 5 | 6–9 | 2 орчим долоо хоног | 2–3 долоо хоног |
| 3–4 | 3 орчим | 5–6 долоо хоног | 6–8 долоо хоног |
| 2 | 3 орчим | 9 орчим долоо хоног | 12 орчим долоо хоног |

Эдгээр бол ойролцоо тооцоо. Зарим зүйл бусдаасаа хавьгүй удаан үргэлжилдэг тул чиний долоо хоногууд тооцоотой таарахгүй байсан ч зүгээр. Нэг дор хэр их хийснээс илүү тогтмол эргэж ирэх нь чухал.

## Сургалтад хамрагдаж байгаа бол

Анги эсвэл bootcamp-д сурч байгаа бол дарааллаар нь явах албагүй. Ангид тухайн сэдэв орох долоо хоногт эдгээр module-ийг дадлага болгон хий. Өөр дадлагын оронд хийнэ, дээр нь нэмж овоолохгүй.

| Анги чинь хүрсэн сэдэв | Хийх зүйл |
| --- | --- |
| MongoDB болон Mongoose-ийн үндэс | Module 1–2 |
| Query болон update | Module 3 |
| Relationship болон `populate` | Module 4 |
| Hook болон aggregation | Module 5 |
| GraphQL болон schema | Module 6 |
| Database-тай ажилладаг resolver | Module 7 |
| Context, auth, алдаа | Module 8 |
| N+1 query болон pagination | Module 9 |
| Apollo Client-тай React | Module 10–12 |

Хичээл болон drill-үүд хүссэн үедээ нээлттэй. Forge step-үүд дарааллаараа явна, учир нь тус бүр өмнөхөөсөө үргэлжилдэг.

## Хоцорвол

Эхнээс нь бүү эхэл. Төслийг forge step-үүд цааш авч явдаг тул эхлээд тэдгээрийг хий, drill-үүд рүүгээ цаг гарсан үедээ эргэж ир. Нэг сэдэв ойлгогдохгүй байвал хичээлээ дахин унш, дараа нь хэд хоногийн дараа drill-ийг дахин оролд. Хоёр дахь удаадаа ихэвчлэн илүү ойлгомжтой болдог.

## TypeScript

Энд байгаа бүх код TypeScript, гэхдээ энэ курс түүнийг заахгүй. Хэрэгтэй зүйлийнхээ ихэнхийг starter-ыг уншаад л сурна. Type дээр гацвал [TypeScript handbook](https://www.typescriptlang.org/docs/handbook/intro.html)-оос хайж үзэхэд сайн.
