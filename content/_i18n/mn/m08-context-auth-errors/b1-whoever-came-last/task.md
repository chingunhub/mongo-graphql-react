Энэ support-оос ирсэн. Мессежийн өнгөнөөс л бүх зүйл ойлгогдоно:

> **TICKET-6024 — "I can see Sam's expenses"** (priority: critical, security)
>
> 1. Хэн нэгэн хамтын laptop дээр app-ыг **нэвтрээгүй** байхад нээгээд өөр хүний expense-үүдийг харсан. Тэр нь үргэлж өмнө нь app ашигласан хүн байдаг.
> 2. Хамааралгүй байж магадгүй: хүмүүс **өөрийнхөө** expense-ийг засахад "You cannot change this expense" гэсэн error авч байна. Хүн бүр, байнга.
> 3. Kai нэг expense алга болсон гэж байна, audit log-д Sam устгасан гэж бий. Sam тэр expense-ийг эзэмшдэггүй. Яаж ийм юм болж чадах вэ?
> 4. Нэг customer улаан banner-ын screenshot явуулсан, дээр нь `Cast to ObjectId failed for value "abc"...` гэж бичсэн байна. Өнгөрсөн улиралд `errors.ts` дотор error masking нэмсэн гэж нэг хүн тангарагласан.

Дөрвөн bug бүгд дөчөөд мөр кодонд байгаа, API нь гаднаас харахад эрүүл. Request болгон сайхан 200 буцаана.

Playground шинж тэмдэг бүрийг тоглуулж харуулдаг: симуляци хийсэн request бүрт шинэ context үүсгэнэ, Apollo Server яг ингэж хийдэг. Кодыг хэт нарийн унших гэж оролдохоосоо өмнө үүнийг ажиллуул.

## Даалгавар

Доорх дүрмүүдийг биелүүл:

1. Token-гүй request, эсвэл хэнийх ч биш token-тэй request өмнө нь юу ирснээс үл хамааран **anonymous** байна.
2. Эзэмшигч өөрийн expense-ийг update хийж чадна. Бусад хүн `FORBIDDEN` авна, expense өөрчлөгдөхгүй.
3. Эзэмшигч өөрийн expense-ийг устгаж чадна. Бусад хүн `FORBIDDEN` авна, expense байрандаа үлдэнэ.
4. Урьдчилан тооцоогүй error-ууд client дээр `Something went wrong` message, `INTERNAL_SERVER_ERROR` code-той хүрнэ. Өөрөө зориуд throw хийсэн error-ууд өөрийн message, code-оо хадгална.

Эвдэрсэн зүйлийг засаад бүтцийг нь хөндөхгүй.

## Hints

### Шинж тэмдэг 1

Resolver-уудыг түр март, `context.ts`-ийг хоёр хүн ашиглаж байгаа мэт унш. Модулийн дээд түвшний утга хэр удаан амьдардаг вэ?

### Шинж тэмдэг 2

Шалгалт санамсаргүй throw хийгээд байгаа юм биш. Хэвлэхэд ижил харагдах ч хэзээ ч тэнцэхгүй хоёр зүйлийг харьцуулж байна. `expense.owner` ямар төрлийн утга вэ, `!==` тэдгээрийг юугаар нь харьцуулдаг вэ?

### Шинж тэмдэг 3 ба 4

3-т хоёр mutation-ийг зэрэгцүүлж тавиад нэг нь хийдэг ч нөгөө нь хийдэггүй зүйлийг ол. 4-т `formatError` дотор `formatted.extensions?.code`-ийг log хийгээд banner-ыг гаргаж үз. Код чинь яг энэ утгыг хайж байна уу?

### Дөрвийг бүгдийг нь

`currentUser` нь `buildContext` дотор, local variable байх ёстой. Эзэмшигчдийг `expense.owner.equals(user._id)`-ээр харьцуул. Ижил эзэмшлийн шалгалтыг `deleteExpense` дотор бас ажиллуул. Мөн Apollo-гийн урьдчилан тооцоогүй error-ын code нь `INTERNAL_ERROR` биш, `INTERNAL_SERVER_ERROR`.
