This course is big on purpose, and you aren't meant to finish all of it. So before you start, here's how to decide how much you want.

## Three stages

The course has three stages, and you can see your progress through each one on the home page.

| Stage | Modules | What it's for |
| --- | --- | --- |
| **1. Backend** | 0–9 | The goal. MongoDB, Mongoose and a complete GraphQL API |
| **2. Full stack** | 10–13 | A stretch. You write real React and finish the app |
| **3. Real systems** | 14–24 | Take the modules you need, when you need them |

Finishing Stage 1 is finishing. You'll have built a real backend, one layer at a time, and that's a good place to stop, or to rest for a while before you go on. Stage 3 doesn't need Stage 2 to unlock, though its later modules do use React.

## How long it takes

It depends on how much time you've got, and there's no prize for rushing. A session here means one sitting.

| Sessions a week | Items each session | Stage 1 | Through Stage 2 |
| --- | --- | --- | --- |
| 5 | 6–9 | About 2 weeks | 2–3 weeks |
| 3–4 | About 3 | 5–6 weeks | 6–8 weeks |
| 2 | About 3 | About 9 weeks | About 12 weeks |

These are estimates, and some items take much longer than others, so don't worry if your weeks don't match. Coming back regularly matters more than how much you do at once.

## If you're taking a class

If you're learning this in a class or a bootcamp, you don't have to go in order. When your class reaches a subject, use these modules as that week's practice. Let them replace other practice instead of piling on top of it.

| Your class reached | Do these |
| --- | --- |
| MongoDB and Mongoose basics | Modules 1–2 |
| Queries and updates | Module 3 |
| Relationships and `populate` | Module 4 |
| Hooks and aggregation | Module 5 |
| GraphQL and schemas | Module 6 |
| Resolvers with a database | Module 7 |
| Context, auth and errors | Module 8 |
| N+1 queries and pagination | Module 9 |
| React with Apollo Client | Modules 10–12 |

Lessons and drills are open whenever you want them. Forge steps stay in order, because each one builds on the last.

## If you fall behind

Don't start over. Forge steps carry the project, so do those first and come back to the drills when you've got time. And if a topic isn't clicking, reread the lesson, then try the drill again a few days later. It often makes more sense the second time.

## TypeScript

All the code here is TypeScript, but this course doesn't teach it. You'll pick up most of what you need just by reading the starters. When a type stops you, the [TypeScript handbook](https://www.typescriptlang.org/docs/handbook/intro.html) is a good place to look it up.
